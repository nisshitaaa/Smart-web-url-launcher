# Service Configuration – Smart Web URL Launcher

## Service Binding

| Property | Configuration |
|---|---|
| Service Binding | `ZUI_WEB_URL_O4` |
| Binding Type | OData V4 – UI |
| Service Definition | `ZUI_WEB_URL` |
| Publishing Status | Published |
| Service Version | 1.0.0 |

## Exposed Entity Sets

The service binding exposes the following entity sets:

- Category
- LaunchHistory
- Website
- CategoryText
- History

## Purpose

The OData V4 UI service binding exposes the RAP business object through an OData service and enables consumption by SAP Fiori Elements.

The binding connects the service definition to the Fiori Elements user interface.

## Development Environment

- SAP BTP ABAP Environment
- Eclipse ABAP Development Tools (ADT)
- OData V4 – UI
- SAP Fiori Elements
