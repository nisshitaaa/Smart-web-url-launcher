# Smart Web URL Launcher – Project Demonstration

## Video Walkthrough

A demonstration of my SAP ABAP RAP project developed on SAP BTP ABAP Environment.

### Features Demonstrated

- Website creation using SAP Fiori Elements
- Automatic URL generation
- Google search URL generation
- Website category selection
- Data validation
- Website launching
- Launch count tracking
- Launch history
- Alias-based search
